# Daspro Jobsheet 12 — Rekursi

Program latihan **rekursi** pada Java: membandingkan pendekatan
iteratif dan rekursif pada perhitungan yang sama.

## Daftar Program

| Program | Deskripsi |
|---------|-----------|
| `Percobaan1.java` | Faktorial — iteratif vs rekursif |
| `Percobaan2.java` | Percobaan rekursi lanjutan |
| `Percobaan3.java` | Percobaan rekursi lanjutan |
| `tugas1.java` | Countdown rekursif vs iteratif |
| `tugas2.java`–`tugas4.java` | Tugas jobsheet |

## Cara Menjalankan

```bash
javac Percobaan1.java
java Percobaan1
```
